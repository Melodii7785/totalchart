## What is this?

TOTALCHART is an early prototype for a music database that brings together streaming, physical sales and digital purchases, with an emphasis on documenting where every figure came from.

## Run it

Open `index.html` in a browser. No build step, framework, package manager or server is required.

## Current prototype

- Plain HTML, a little CSS and vanilla JavaScript.
- Retro, early-web presentation.
- Britney Spears demo profile and chart table.
- Missing physical and digital sales are clearly marked as unavailable.
- Methodology notes explain why unlike units should not automatically be added together.

## Data policy

The stream counts currently displayed are transcribed from a user-provided screenshot and have not been independently verified. They are not presented as confirmed current Spotify totals. Sales figures are not yet researched. Do not treat missing data as zero, and do not publish a combined total until the sources, territories, date ranges and calculation method are documented.

## Research starting points

- [Luminate methodology](https://support.luminatedata.com/portal/en/kb/articles/methodology)
- [IFPI Global Music Report 2026 methodology](https://gmr.ifpi.org/downloads/GMR2026_Methodology.pdf)

## Status

Early prototype. The next major job is building a reliable, source-cited data model before expanding the chart database.
